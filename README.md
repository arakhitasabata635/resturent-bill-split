# Restaurant Bill Split Calculator 🍽️

A simple web application that helps groups split a restaurant bill easily. Enter the total amount, select the number of people, add tip percentage, and get each person’s share instantly.

---

## 🚀 Features
- 🧮 Input total bill amount  
- ➕ Select number of people sharing  
- 💰 Add tip percentage (optional)  
- 🔍 Calculate each person’s share instantly  
- 🧩 Minimal and responsive UI for easy use

---

## 🛠 Tech Stack
- **React** (using Vite)  
- **Bootstrap** for UI & styling  
- **JavaScript (ES6+)** for logic  
- **CSS** for custom styles  

---

## 🔧 How to Run Locally
```bash
git clone https://github.com/arakhitasabata635/resturent-bill-split
cd resturent-bill-split
npm install
npm run dev
```
